# Ícones

Ícones do conjunto **Material Symbols** (Google), estilo *Outlined*, baixados de
<https://github.com/google/material-design-icons> (mesmos ícones de
<https://fonts.google.com/icons>). Licença **Apache 2.0** (texto completo em `LICENSE`): uso livre,
inclusive comercial, desde que a licença acompanhe os arquivos — por isso ela vai junto no `.exe`.

O SVG fica como foi baixado (preto); o programa pinta na cor do tema ao carregar
(`interface/icones.py`). Só entram ícones que combinam de verdade com o lugar, aprovados por foto.

| Arquivo | Onde aparece |
|---|---|
| `calendar_month.svg` | Aba Agenda; botão de calendário dos campos de data |
| `receipt_long.svg` | Aba Pedidos |
| `content_cut.svg` | Aba Planos de corte |
| `schedule.svg` | Etiqueta de prazo atrasado |
| `check.svg` | Item entregue (falta zerada) |
| `light_mode.svg`, `dark_mode.svg` | Botão de trocar entre modo claro e escuro |
| `delete.svg` | Aba Lixeira; botão Excluir |
| `restore_from_trash.svg` | Botão Restaurar (Lixeira) |
| `delete_forever.svg` | Botão Excluir de vez (Lixeira) |
| `person.svg` | Filtro "Registrado por" |
